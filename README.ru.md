# msi-ultrapower

**Режимы питания для ноутбуков MSI в KDE Plasma.**

[English](README.md) · [Türkçe](README.tr.md) · **Русский** · [Español](README.es.md) · [العربية](README.ar.md)

Одним нажатием переключает ноутбук MSI между режимами производительности, баланса и батареи.
Каждый режим вместе настраивает профиль питания, частоту обновления и яркость экрана, вентилятор
и режим EC, турбо-режим процессора, подсветку клавиатуры, энергосбережение устройств и видеокарту
NVIDIA, а при ошибке на любом шаге всё отменяет.

![Окно «Режимы питания»](docs/screenshot.png)

## Установка

В Arch, CachyOS, EndeavourOS или Manjaro с KDE Plasma 6:

```sh
curl -fsSL https://raw.githubusercontent.com/bugrakaann/msi-ultrapower/main/install.sh | bash
```

Чтобы обновить, выполните ту же команду ещё раз. Для управления вентилятором, режимом EC,
Cooler Boost и пределом заряда установите также драйвер
[msi-ec](https://github.com/BeardOverflow/msi-ec) из AUR (`msi-ec-dkms-git`) и перезагрузитесь.
Без него всё остальное тоже работает.

```sh
git clone https://github.com/bugrakaann/msi-ultrapower.git

make install
```

## Как пользоваться

1. Откройте **Режимы питания** в меню приложений.
2. Выберите режим. Окно покажет, что именно изменится на вашем ноутбуке.
3. Нажмите **Применить** и введите пароль.

Чтобы вернуть всё как было до первого использования, нажмите **Восстановить прежние настройки**.
Режимы батареи полностью отключают NVIDIA после перезагрузки; окно сообщит, когда она нужна.

### Режимы

| Режим | Что делает |
|---|---|
| **Максимальная производительность** | Профиль производительности, турбо, Cooler Boost, максимальная частота, яркость 100% |
| **Производительность · Ручной вентилятор** | То же, с вашей кривой вентилятора (настраивается в MControlCenter) |
| **Сбалансированный** | Сбалансированный профиль, автоматический вентилятор, яркость 60%, NVIDIA засыпает в простое |
| **Максимальное время работы** | Энергосбережение, без турбо, яркость 30%, NVIDIA выключена, устройства спят, подсветка клавиатуры выключена |
| **Максимальное время работы · Низкая частота** | То же, плюс минимальная частота обновления экрана |

Внешние мониторы сохраняют разрешение и частоту. Выходы, подключённые к NVIDIA, в режимах батареи
выключаются, потому что NVIDIA выключена.

### Настройки (⚙)

- **Предел заряда** – заряжать батарею до 60, 80 или 100%. 60–80% продлевают срок службы батареи.
- **Автоматический режим** – переключать режимы при подключении и отключении зарядки.
- **Не спрашивать пароль администратора** – смена режимов, предел заряда и автоматический режим без пароля.
- **Запускать в системном лотке при входе** – переключать режимы и видеть батарею, потребление и температуру из лотка.
- **Параметры режимов батареи** – сон устройств, выключение Bluetooth.
- **Язык** – English, Türkçe, Русский, Español, العربية.

### Командная строка

```sh
msi-ultrapower balanced            # performance, performance-manual, balanced, battery, battery-low-hz
msi-ultrapower battery --dry-run   # показать изменения, ничего не меняя
msi-ultrapower restore             # вернуть настройки до первого режима
msi-ultrapower charge 80           # предел заряда: 60, 80 или 100
msi-ultrapower status              # текущие значения
msi-ultrapower doctor              # что работает на этом ноутбуке
```

## Совместимость

Разработано на MSI GF65 Thin 9SEXR. Программа не рассчитана на одну модель, а определяет, что
поддерживает ваш ноутбук: режимы EC и вентилятора, частоты экрана (120–240 Гц), турбо Intel или
AMD и наличие NVIDIA. Отсутствующие функции пропускаются и показываются в окне.

- **Переключатель MUX:** если в BIOS выбран режим GPU *Discrete*, экраном управляет NVIDIA, и
  программа не будет её выключать. Для полноценных режимов батареи выберите в BIOS *MSHybrid/Optimus*.
- **TLP, auto-cpufreq, tuned** конфликтуют с профилями питания; программа предупредит, если один из них запущен.

Чтобы сообщить, как программа работает на вашей модели,
[создайте issue](https://github.com/bugrakaann/msi-ultrapower/issues/new?template=model-report.md)
с выводом `msi-ultrapower doctor`.

## Удаление

```sh
msi-ultrapower restore        # необязательно: вернуть прежние настройки
sudo pacman -R msi-ultrapower
```

Ваши настройки остаются в `~/.config/msi-ultrapower` и `~/.local/share/msi-ultrapower`.

## Решение проблем

**После выбора режима батареи не запускается рабочий стол.** Перейдите в текстовую консоль
(Ctrl+Alt+F3), войдите и выполните:

```sh
sudo /usr/lib/msi-ultrapower/msi-ultrapower-gpu-boot hybrid
```

Затем перезагрузитесь. Это удаляет только блокировку NVIDIA, добавленную msi-ultrapower.

**Что-то не получилось.** Нажмите **Показать журнал** в окне или запустите тот же режим из
терминала, чтобы увидеть полный вывод.
